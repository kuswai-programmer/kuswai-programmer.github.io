# Kuswai Hamza — Portfolio
Responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Deploy
This repository is a GitHub Pages user site. In Settings → Pages, choose **GitHub Actions** as the source. The included workflow publishes the static site on every push to main.

## Personalization
The profile photo is at assets/profile.jpg. Project visuals are temporary CSS mockups and are labelled as concepts. Replace them with real app screenshots when available.
